## Breakpoint Summary

```
Device Type    Width Range      Layout Changes
───────────────────────────────────────────────────
Desktop        ≥ 1025px         Full desktop layout
Small Laptop   769-1024px       Reduced spacing
Tablet         481-768px        2-column grids
Mobile         ≤ 480px          Single column
iPhone SE      ≤ 375px          Extra compact
```

## CSS Media Query Structure

```css
/* 📱 Mobile First Approach */

/* Base styles (mobile) */
.element {
  font-size: 14px;
  padding: 10px;
}

/* Tablet */
@media (min-width: 481px) {
  .element {
    font-size: 15px;
    padding: 15px;
  }
}

/* Desktop */
@media (min-width: 769px) {
  .element {
    font-size: 16px;
    padding: 20px;
  }
}

/* Large Desktop */
@media (min-width: 1025px) {
  .element {
    font-size: 18px;
    padding: 25px;
  }
}
```
