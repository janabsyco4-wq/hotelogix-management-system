## Project Overview

Hotelogix is a comprehensive, AI-powered hotel management system featuring:

### 🎯 Core Technologies
- **Frontend:** React.js 18, React Router v6
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas with Mongoose ODM
- **AI/ML:** Python, Flask, scikit-learn, NLTK
- **Deployment:** Vercel (Frontend), Ngrok (Backend Tunneling)
- **Payment:** Stripe API Integration

### 🤖 AI Features
1. **Dual-Model Room Recommendation Engine**
   - Random Forest Classifier (79% accuracy)
   - Gradient Boosting Regressor (R² = 0.60)
   - Trained on 100,000+ synthetic samples

2. **NLP Chatbot**
   - 555,936 training patterns
   - 64 intents coverage
   - 99.87% intent classification accuracy
   - TF-IDF + Logistic Regression pipeline

### 📱 Key Features
- Complete hotel booking system with online payments
- AI-powered room recommendations for 7 user types
- Intelligent chatbot with hotel-specific knowledge
- Real-time admin dashboard with analytics
- Mobile-responsive design (all devices)
- Dining reservations and table booking
- Deals, packages, and loyalty programs
- Automated cancellation and refund processing

## How to Run

### Prerequisites
```bash
Node.js v18+
Python 3.8+
MongoDB Atlas account
Stripe account
Ngrok account (optional)
```

### Installation
```bash
# Clone repository
git clone <repository-url>

# Install dependencies
npm install
cd client && npm install
cd ../ai-model && npm install

# Setup environment variables
cp .env.example .env
# Add your API keys and database URL

# Generate Prisma client
npm run prisma:generate

# Seed database
npm run prisma:migrate
```

### Running the Application
```bash
# Start all services (server + client)
npm run dev

# Start with ngrok tunnel
npm run dev:tunnel

# Start individual services
npm run server   # Backend only
npm run client   # Frontend only
npm run ngrok    # Ngrok tunnel only
```
